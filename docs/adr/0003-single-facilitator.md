# ADR-0003: Single Facilitator Model

Status: Accepted

Date: 2026-10-05

Source: SPEC_DOC.md §9 D-3

## Context

Multi-user participation (PRD §7 secondary users vs §15 future multi-user).

## Decision

MVP: single Facilitator drives; Participants speak in the meeting; single-editor session lock.

## Rationale

§15 explicitly defers multi-user auth and collaborative editing.

## Revisit if

§15 items get scheduled.
