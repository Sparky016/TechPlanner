# ADR-0007: Performance Targets and Pacing

Status: Accepted

Date: 2026-10-05

Source: SPEC_DOC.md §9 D-7

## Context

No performance or pacing targets.

## Decision

NFR-1–NFR-5 values; ≤ 3 questions per AI turn.

## Rationale

"Real time" in a live meeting implies sub-3 s responsiveness; capping questions keeps the meeting usable.

## Revisit if

Measured meeting feedback.
