# ADR-0010: Source Ingestion Limits

Status: Accepted

Date: 2026-10-05

Source: SPEC_DOC.md §9 D-10

## Context

Which attachments / Confluence links to ingest.

## Decision

SR-2.3–SR-2.5 limits (one-level links; text/PDF/DOCX/images with size caps; token budget with visible truncation).

## Rationale

Maximise useful context while keeping model input bounded and transparent.

## Revisit if

Context limits or needs change.
